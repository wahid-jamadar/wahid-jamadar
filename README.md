## 🚀 Selected Projects  

- **RAG-based AI Banking Assistant (AAIDC Project):** A Retrieval-Augmented Generation chatbot that answers finance-related questions using custom documents. Implements ChromaDB with HuggingFace embeddings and multiple LLMs (GPT, etc.). Automatically chunks documents and performs vector similarity search to generate accurate answers.
- **LIST Assistant – AI Chatbot:** A conversational agent built for List Software. Real-time chat powered by integrated LLMs (Groq/OpenAI) and supports voice input. Modular React/Node application with WebSocket communication and live NLP capabilities. Designed as an embeddable chat widget for websites, ideal for customer support and task automation.
- **Content Toxicity Scanner:** An AI-driven moderation platform detecting hate speech/toxicity across channels. Centralized FastAPI backend (Python) using scikit-learn models for text classification. Supports a web dashboard, YouTube comment syncing, and a Chrome extension for real-time page scanning. It classifies content severity and suggests moderation actions automatically.
- **Online Payments Fraud Detection:** A Flask web app with an ML engine (Random Forest) to flag fraudulent transactions. Built for financial institutions to monitor payment systems. Features an interactive dashboard and real-time prediction on transaction data, leveraging Python, Pandas, and scikit-learn.
- **Blood Bank Management Website:** A responsive HTML/CSS/JavaScript site connecting donors and recipients. Includes user login, donor panel, search by blood group/location, and a mobile-friendly UI. Built with vanilla frontend technologies (with Firebase/JSON for storage).
- **Mobile Store Management (Java):** A console-based inventory system written in Java. Manages stock, billing, and data persistence via serialization. Demonstrates core Java skills (OOP, file I/O, exception handling) in a single-module application.
